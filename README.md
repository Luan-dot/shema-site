# Шема — who supplies the Macedonian state

Built site for **Шема / Šema**, a descriptive map of North Macedonia's public procurement record:
e-nabavki.gov.mk (2008–2026), OpenTender OCDS (2011–2024) and Open Finance Treasury payments.

Live: https://luan-dot.github.io/shema-site/

A description of a public record with known gaps, not evidence of wrongdoing.
